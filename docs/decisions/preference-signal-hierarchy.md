# 선호도 신호의 우선순위

## Decisions

- 사용자별 예상 선호도는 개인의 실제 선택과 평가를 가장 우선하고, 데이터가 부족할 때 비슷한 음식 취향 유형, 연령대·성별 집단, 전체 사용자 경향을 차례로 보조 신호로 사용한다.
- 연령대와 성별은 신규 사용자의 초기 추정을 위한 보정값으로만 사용한다. 개인 행동 데이터가 쌓일수록 해당 가중치를 점진적으로 감쇠시키고, 충분한 개인 데이터가 있으면 실제 행동이 추천을 지배한다.
- 음식 취향 유형은 연령대나 성별로 정의하지 않고 실제 선택과 평가 패턴이 비슷한 사용자들을 바탕으로 만든다.
- 축적된 데이터를 지속적으로 분석해 선호 예측과 후보 구성 모델을 개선한다.

## Boundaries

- 연령대·성별 가중치의 초기 크기와 감쇠식, 취향 유형 생성 방식, 모델 갱신 주기와 배포 기준은 아직 정하지 않았다.
- 데이터가 쌓였다는 이유만으로 검증 없이 운영 모델을 자동 변경하는 것을 승인하는 결정은 아니다.

## Why

개인 기록이 없는 초기에는 집단 경향이 유용한 출발점이 될 수 있지만, 계속 유지하면 실제 취향보다 인구통계적 평균을 우선하는 결과가 생긴다. 행동 기반 취향 유형과 개인 기록으로 점차 이동해야 초기 추천과 장기 개인화를 함께 달성할 수 있다.

## Reconsider when

- 품질 검증에서 연령대·성별 보정이 초기 추천 품질을 유의미하게 높이지 못하거나 특정 집단의 추천 품질을 일관되게 낮추는 경우.
- 개인 데이터가 충분한 사용자에게도 인구통계 신호를 유지하는 편이 반복 검증에서 유의미하게 더 좋은 결과를 내는 경우.

## Still-rejected alternatives

- 연령대·성별 가중치를 개인 데이터와 무관하게 계속 유지 — 실제 행동과 충돌해도 고정된 집단 평균이 추천에 남는다. 반복 검증에서 지속 가중치의 이점이 확인되면 재검토한다.
- 인구통계 정보로 음식 취향 유형을 직접 정의 — 실제 선택 패턴이 아니라 속성에 따라 사용자를 고정한다. 행동 기반 유형보다 추천 품질이 낫다는 증거가 생기면 재검토한다.
