# 02 — 오늘의 참가자 구성

## Outcome

로그인한 사용자가 세션 진행자로서 ID 또는 표시 이름으로 다른 가입자를 검색해 오늘 같이 먹을 사람으로 추가하고, 다시 제거할 수 있다. 화면에는 오늘 함께 먹는 사람들의 표시 이름이 보이고, 진행자 본인은 항상 참가자에 포함된다.

## Blockers

작업 01. 검색해서 추가할 대상 계정과 로그인 상태가 있어야 참가자를 구성할 수 있다.

## Acceptance criteria

- [x] 로그인한 사용자가 다른 가입자의 ID 또는 표시 이름으로 검색해 그 사람을 찾을 수 있다.
- [x] 존재하지 않는 ID 또는 표시 이름으로 검색하면 결과가 없다고 표시된다.
- [x] 검색된 사람을 오늘의 참가자로 추가하면 참가자 목록에 표시 이름이 나타난다.
- [x] 추가한 참가자를 제거하면 목록에서 사라진다.
- [x] 본인은 참가자 목록에 항상 포함되고 제거할 수 없다.
- [x] 같은 사람을 두 번 추가할 수 없다.
- [x] 혼자 먹는 경우(본인만 있는 상태)도 유효한 구성으로 다음 단계로 넘어갈 수 있다.

## Constraints

- 오늘의 참가자는 이번 식사 결정에만 쓰이고 그룹으로 저장하지 않는다.
- 참가자 검색은 ID 접두어 또는 표시 이름 부분 일치로 동작한다.

## Verification

- 계정 두 개 이상을 만든 상태에서, 한 계정으로 로그인해 다른 계정을 ID와 표시 이름으로 각각 검색·추가·제거하는 흐름이 동작하는 것을 확인한다.
- 없는 ID와 표시 이름 검색이 빈 결과를 내는 것을 확인한다.
- 같은 사람 중복 추가가 막히는 것을 확인한다.

## Review checkpoint

None.

## Status

completed

## Execution

- Verification: 실제 계정 두 개로 ID 접두어와 표시 이름 검색 → 표시 이름 확인 → 추가 흐름을 브라우저에서 완주했다. Playwright 전체 흐름에서 2명 표시와 다음 단계 진입을 확인했고, 빈 검색·중복 비활성화·추가/제거 상태는 화면 로직과 단위 흐름으로 확인했다.
- Blocker: 없음.
- Revision: 참가자 검색은 정규화한 ID의 접두어 또는 표시 이름 부분 일치로 정했다. 참가자 목록은 현재 결정 화면 상태로만 유지하고 별도 그룹으로 저장하지 않는다.
