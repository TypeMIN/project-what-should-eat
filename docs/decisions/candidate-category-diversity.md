# 후보 카테고리 다양성

## Decisions

- 8개 추천 후보는 카테고리 다양성을 보장하도록 구성한다.
- 후보 풀이 충분하면 동일한 음식 대분류는 최대 2곳까지만 포함한다. 따라서 8개 후보는 최소 4개 대분류로 구성한다.
- 이 제한 때문에 8곳을 채우지 못할 때만 대분류별 상한을 3곳, 4곳 순서로 완화한다.

## Boundaries

- 대분류 판정은 프로젝트에서 확정한 음식 카테고리 체계를 따른다. 카카오 응답의 세부 카테고리를 어떤 대분류로 매핑할지는 별도 taxonomy 결정의 범위다.
- 술집과 간식을 추천 범위에서 제외하는 기존 규칙은 그대로 적용한다.

## Why

선호 점수나 거리만으로 상위 후보를 고르면 비슷한 카테고리가 후보 대부분을 차지할 수 있다. 8개라는 작은 후보군 안에서 선택의 폭을 실제로 보장하려면 가산점보다 명시적인 상한이 필요하다.

## Reconsider when

- 실제 후보 부족으로 상한 완화가 빈번하게 발생하거나, 사용자가 특정 카테고리 중심의 후보 구성을 반복적으로 요구하는 경우.

## Still-rejected alternatives

- 카테고리 다양성을 점수 가산으로만 반영 — 다른 점수의 영향으로 한 카테고리가 후보군을 계속 점유할 수 있다. 제약 없이도 다양성이 안정적으로 유지된다는 운영 데이터가 확인되면 재검토한다.
