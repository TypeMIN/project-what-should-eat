# 추천 학습과 개인 평가

## 사용자에게 보이는 결과

- 오늘의 참가자 모두가 강하게 싫어하는 곳을 피하면서도 카테고리와 신규성 측면에서 다양한 8개 후보를 받는다.
- 세션 진행자는 기존처럼 A/B 선택을 끝내고, 최종 식당 선택 자체는 개인 취향으로 오해되지 않는다.
- 참가자는 자신이 포함된 지난 선택에서 `좋다`, `싫다`, `실제로는 방문하지 않음` 중 하나를 남기고 나중에 바꿀 수 있다.
- 사용자는 추천으로 선택하지 않은 실제 방문 식당도 검색해 `좋다` 또는 `싫다` 평가를 남길 수 있다.
- 평가와 진행자의 A/B 선택이 쌓일수록 다음 후보의 개인·그룹 적합도가 개선된다.

## 승인된 범위

- 특정 식당의 직접 `싫다` 평가는 해당 사용자가 참가하는 후보에서 그 식당을 제외한다.
- 서로 다른 두 식당에서 같은 대분류에 `싫다` 평가를 남기면 해당 사용자에게 그 대분류를 강한 비선호로 간주한다.
- 강한 비선호를 통과한 후보는 참가자별 예상 선호도의 평균으로 정렬한다.
- 개인의 직접 평가와 A/B 행동을 가장 우선하고, 행동이 비슷한 사용자와 연령대·성별 집단의 경향은 개인 데이터가 부족할 때만 보조한다.
- 동일 음식 대분류는 최대 2곳으로 제한하고, 이 제약으로 8곳을 채울 수 없을 때만 상한을 점진적으로 완화한다.
- 8개 후보의 첫 구성은 합의 후보 4곳, 신규 탐색 2곳, 재발견 1곳, 변화 후보 1곳으로 시작하며 해당 역할이 부족하면 안전한 합의 후보로 채운다.
- A/B 승패는 진행자의 행동 신호로만 저장한다. 최종 식당 선택은 개인 선호 신호로 사용하지 않는다.
- 개인 평가는 최종 선택 이력과 별도로 유지하고, `실제로는 방문하지 않음`은 부정 평가로 사용하지 않는다.

## 수용 기준

- 참가자 중 한 명이라도 특정 식당을 `싫다`로 평가했다면 그 식당은 8개 후보에 포함되지 않는다.
- 충분한 후보 풀이 있으면 동일 대분류가 3곳 이상 포함되지 않는다.
- 개인 평가가 없는 사용자는 연령대·성별 및 전체 경향의 도움을 받고, 개인 평가가 쌓일수록 개인 행동이 결과를 지배한다.
- 진행자의 각 A/B 승패가 저장되지만 다른 참가자의 개인 행동으로 기록되지 않는다.
- 최종 식당 선택만으로 `좋다` 또는 `싫다`가 생성되지 않는다.
- 각 참가자는 본인이 참여한 결정에 평가를 한 번 남기고 다른 선택으로 수정할 수 있다.
- `실제로는 방문하지 않음`을 선택한 기록은 선호 점수와 개인 방문 기록에 영향을 주지 않는다.
- 식당명 검색으로 추천 밖 실제 음식점을 찾아 `좋다` 또는 `싫다` 평가를 저장하고 수정할 수 있다.

## 확정된 제약과 근거

- 술집과 간식은 기존 음식 카테고리 범위 결정에 따라 제외한다.
- 추천은 오늘 참가자의 데이터만 결합한다.
- 한 참가자의 강한 비선호를 평균 만족도보다 먼저 보호한다.
- 연령대와 성별은 초기 추정값이며 개인 행동이 쌓이면 감쇠한다.
- 개인 평가가 진행자의 대리 선택이나 최종 선택보다 강한 학습 신호다.

## 가정

- 카테고리 강한 비선호는 서로 다른 식당 두 곳의 `싫다` 평가부터 적용한다.
- 음식 대분류는 카카오 카테고리 경로에서 `음식점` 바로 아래 단계를 사용한다.
- 행동 유사 사용자 신호는 공통 평가 카테고리가 충분할 때만 사용하고, 그렇지 않으면 인구통계·전체 경향으로 대체한다.
- 슬롯 배분 `4·2·1·1`은 실제 선택과 평가 데이터 분석으로 조정할 수 있는 첫 운영값이다.

## 제외 영역과 이유

- 자동 모델 재학습과 무검증 자동 배포 — 학습 품질 지표와 실험 체계가 아직 없으므로 비교·평가 데이터를 먼저 정확히 축적한다.
- 알레르기나 못 먹는 음식 입력 — 기존 제품 범위 밖이며 `싫다` 평가는 안전 조건을 대신하지 않는다.
- 인구통계 속성만으로 취향 유형을 고정하는 방식 — 실제 행동 기반 유형이라는 제품 결정을 위반한다.

## 남은 위험

- 초기에는 평가 데이터가 적어 무작위성, 거리, 전체 경향이 추천 결과에 더 크게 작용한다.
- 카카오 카테고리의 대분류 품질이 낮은 장소에서는 다양성 제약과 카테고리 비선호 추론이 부정확할 수 있다.
- 식후 평가 참여가 낮으면 진행자의 A/B 행동에 비해 다른 참가자의 신호가 느리게 쌓인다.
