# 음식 카테고리 taxonomy

## Decisions

- 추천 후보 범위에서 술집, 간식(제과·베이커리류)은 제외한다.
- 카카오의 "아시아음식 > 동남아음식"은 별도 대분류로 승격하지 않는다. "동남아"는 아시아음식 대분류 아래의 중분류로 유지한다.

## Boundaries

- 이 결정은 술집·간식·동남아 3가지에만 적용된다. 샤브샤브, 뷔페, 도시락, 퓨전요리, 패밀리레스토랑, 패스트푸드처럼 Phase 0 조사에서 함께 발견된 나머지 소수 카테고리의 포함 여부는 아직 정하지 않았다.
- 대분류/중분류 전체 매핑 표는 `docs/research/phase0-kakao-category-analysis.md`의 초안을 참고하되, 이 문서에 명시된 항목 외에는 확정된 것으로 보지 않는다.

## Why

Phase 0 조사(`docs/research/phase0-kakao-category-analysis.md`) 결과, 카카오 음식점(FD6) 카테고리에는 술집·간식류가 섞여 있었지만 이는 "오늘 뭐 먹지"가 뜻하는 한 끼 식사 후보로 보기 애매해 제외했다. "동남아"는 카카오 데이터에서 이미 아시아음식의 중분류(`아시아음식 > 동남아음식 > 베트남음식`)로 나타나므로, 브리프가 가정했던 것처럼 별도 대분류로 재구성할 실익이 없다고 판단했다.

## Reconsider when

- 실제 사용자 데이터에서 술집·간식류를 찾는 요청이 반복적으로 나타나는 경우.
- 아시아음식 대분류 안에서 동남아음식 비중이 커서 별도 대분류로 분리하는 것이 추천 다양성에 유의미한 차이를 만드는 경우.
